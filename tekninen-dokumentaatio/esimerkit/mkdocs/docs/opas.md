# Opas: ensimmäinen yhteenveto

Oppaassa lasketaan yhden aseman yhteenveto valmiista tiedostosta. Aikaa
kuluu viisi minuuttia, eikä aiempaa kokemusta ohjelmasta tarvita.

## Lukematiedosto

Asema lähettää lukeman rivinä, jonka kentät erotetaan puolipisteellä:
asema, aika, lämpötila ja kosteus. Tiedostossa `lukemat.csv` on neljä
lukemaa kahdelta asemalta.

## Yhteenveto

Anna tiedosto ja aseman tunnus:

<!-- komento: python3 -m saa lukemat.csv --asema kumpula -->
```text
kumpula: 3 lukemaa, -3.5 ... -1.5 C, keskiarvo -2.5 C
```

Seuraavaksi: [ohjeet](ohjeet.md) kertoo, mitä virheilmoitukset
tarkoittavat.
